# 공고·공개 검색 계약

상태: 미작성 계약의 골격 · 주담당: 민규담당

기준: [상세 설계](../../PLAN_상세설계.md), [작업 지침](../../AGENTS.md).

## 다룰 내용

민규는 공고 작성·수정, 공개·비공개 위치, 검색에 제공할 공개 데이터 경계를 이 파일에 작성한다. 검색 조건·카드·커서의 계약은 종현 소유인 [search.md](search.md)에 작성한다. 이 파일은 민규만 수정한다.

## 작성할 계약

- 호출 주체·인증·권한과 입력 검증
- 요청·응답 필드 및 정상·실패 예시
- 상태 전이·중복 요청·재시도 처리
- 공개 범위·로그 제외 필드
- 민규·종현 연결 사항과 완료 검증 기준

## 미정 사항

정책·공급사·수치·실제 API 경로는 합의 전까지 임의 확정하지 않는다. 이 문서는 아직 완성된 API 명세가 아니다.
