## 완료·평가: 확인한 뜻과 상태

예: 14:00~15:00 동행.

```text
15:00 전   둘 다 완료 확인 불가
15:00 이후
  나    [동행 완료 확인] → 내 평가 작성 → 제출
                         └→ 상대에게 “완료를 확인했어요” 알림
  상대  [동행 완료 확인] → 상대 평가 작성 → 제출
                         └→ 나에게 알림

내가 완료 확인 + 내 평가 제출 + 상대 평가 존재
  → 내가 상대 평가를 볼 수 있는 기본 조건 충족
상대도 자기 완료 확인 + 자기 평가 제출을 해야 내 평가 열람 가능
```

- 여기서 ‘확정하고 평가’는 만남 전 최종 수락을 다시 받는 것이 아니라, 문맥상 **동행 완료 확인 후 평가**로 해석한다.
- 완료 확인과 평가 제출은 별개다. 확인 후 평가를 나중에 쓸 수 있어야 한다.
- 개인별 완료 확인 시각과 개인별 평가 제출을 저장할 설계가 필요하다. 전역 COMPLETED 하나로 두 사람의 평가 가능 여부를 함께 잠그면 안 된다.
- 완료 알림에는 평가 내용·별점·당도 변화를 싣지 않는다.
- “상대가 아직 평가하지 않았어요”와 “내 평가를 남겨야 볼 수 있어요”를 구분한다.
- 평가 열람 제한은 상세 화면 외에 프로필 후기·미리보기·알림에도 일관되어야 한다.
- 기존 “양측 완료 확인 이후 평가 가능”은 이번 선택으로 폐기한다.
- 사용자 추가 확정: **동행 종료 후 7일까지 평가 작성, 양쪽 모두 제출했을 때 공개. 7일 뒤 자동 공개는 삭제한다.** 한쪽이 기간 안에 제출하지 않으면 해당 동행 후기는 비공개로 남는다.
- 기존 **24시간 자동 완료**를 새 조건에 그대로 연결하지 않는다. 자동 완료가 실제 본인 확인을 대신하거나 평가 열람을 열어서는 안 된다.
- 취소·분쟁·차단 등 예외에서 이미 제출한 평가를 보존/보류하는 규칙은 아래 정책 질문 문서에 명시한다.

## 동행 취소와 차단

```text
약속 상세 / 상대 메뉴
  [동행 취소] → 동행만 취소 → 상대와의 차단 관계는 만들지 않음
  [차단]      → 영향 안내 → 상대 차단 + 진행 중 동행 취소

차단 목록 → [차단 해제]
  → 관계만 해제, 취소된 동행·종료 요청은 자동 복구하지 않음
```

진행 중 동행이 있을 때 차단 확인창에는 함께 취소된다는 사실을 표시한다. 상대에게는 동행 취소 결과를 전달하며 차단한 사실을 별도 알림으로 노출하지 않는 안으로 설계한다. 기존 SAFE-03에 따라 이미 완료된 동행과 신고 이력은 차단 때문에 삭제/취소하지 않는다. **한쪽만 완료 확인한 때를 완료된 동행으로 볼지**는 새 P1 때문에 생긴 경계 사례이며 추가 판단 항목이다.

## 관심친구 추가 답변 — 기본 흐름 선택 완료

- 누구나 비공개 저장. 신청했지만 확정되지 못한 상대의 다음 공고 소식과 과거 동행에게 보내는 초대가 사용자 목적이다.
- 공고를 전체 공개로 먼저 작성한 다음 초대한다. 사전 ‘관심 있어요 → 공고 작성’ 단계는 사용하지 않는다.
- 초대에서 공고 확인 후 직접 신청, 작성자 최종 수락 시 확정.
- 알림 바로가기와 Me의 신청·초대 관리 모두 제공. 기본 최신 초대순에서 **수신자가 저장한 관심친구** 우선, 각 묶음 안에서 최근 받은순.
- S1 최신 수정 확정: ‘시간순’에서는 관심친구 상단 고정과 그룹을 해제하고 **전체 초대를 동행 시작이 빠른순**으로 배치한다. 최신 초대순에서만 관심친구 우선을 유지한다. [확정 스케치](FAVORITE_SORT.html).
- 시간순 관계 표시: 이름 옆에 관심친구 ★, 이전 동행 ‘동행한 적 있음’, 둘 다면 두 표시. 처음인 사람은 별도 표시 없음. 나머지 선택은 사용자 확정.
- 저장 해제로 진행 초대·신청·확정 동행은 취소하지 않는다.
- N1 A 확정: 관심친구 저장 시 새 공고 알림 기본 켜짐, 사람별 끄기 가능.
- N2 B+최신 수정 확정: 모든 초대를 기본 알림으로 제공. Me > 알림 설정에서 ‘처음 보는 사람의 초대 알림’ 스위치 하나로 조절. 서비스 UI에서 푸시/종을 분리하지 않음. 꺼도 Me 받은 초대 유지.
- S2 A 확정: 수신자가 저장하지 않았고 동행 경험도 없는 사람만 ‘처음 보는 사람’. 저장한 상대와 과거 동행은 이 설정의 대상이 아님. 개별 푸시·종 스위치 제안은 폐기.
- 24시간·하루 3건/주 10건·30일 보관함 등 이전 숫자 묶음은 미채택이다.
