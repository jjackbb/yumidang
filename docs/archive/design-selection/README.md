# 과거 IA·유저플로우·화면 선택 기록

이 폴더는 이전 구조의 추적·비교용 보관 자료다. 현재 요구사항을 정하기 위해 과거 Notion이나 화면 초안을 다시 기준으로 가져오지 않는다.

## 현재 기준 문서

1. [PRD](../../planning/requirements/PRD.md): 성인 여성만 가입·이용하는 제품 목표·범위.
2. [IA](../../planning/design/IA.md): 현재 메뉴·화면 구조.
3. [유저플로우](../../planning/design/USER_FLOW.md): 현재 사용자 행동·분기·완료 흐름.

세 문서에 명시된 결정이 아래 과거 기록과 충돌하면 현재 기준을 우선한다. 세부 미결정 정책을 이 정리로 새로 확정하지 않는다.

별도 이름의 과거 `IA.md`·`USER_FLOW.md` 원문 사본은 로컬에서 확인되지 않았다. 외부 원문 전체를 복사한 것으로 표시하지 않는다. 기존 HTML·스크린샷·검증 증거는 원래 보관 위치를 유지한다.

## Notion 출처 — 과거 기록용

- [기존 Notion IA·유저플로우가 있던 페이지](https://app.notion.com/p/3ca626093f2e80ce9c3dd24f35f168ec?source=copy_link#3e2626093f2e8004ba6fd5ac95e5320c): 사용자가 전달한 링크. 유저플로우 본문을 읽어 새 문서를 작성할 때 참고했다.
- 원문은 2026-09-21 HTML 스냅샷의 24개 화면·119개 상태를 분석한 기록이다. 화면·정책 설계와 실제 동작 여부가 섞여 있어 새 서비스의 구현 완료 근거로 사용하지 않는다.
- 외부 Notion 페이지는 수정·삭제하지 않았다. 링크는 출처 추적용이며 현재 설계·구현의 필수 입력이 아니다.
