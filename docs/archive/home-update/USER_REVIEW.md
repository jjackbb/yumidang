# 사용자 화면 확인

상태: 사용자 확인 대기. 에이전트 브라우저 동작 검증은 통과했으며 실제 사용자 검증과 구분한다.

확인 화면: 홈, 로그인/가입, Me 신청 두 탭, 주차별 이벤트.

- 로그인 상단 탭 없이 하단 가입 버튼으로 이동하는 흐름이 의도한 형태인지
- Me의 신청한 동행/받은 신청을 상단에 함께 둔 배치
- D-7부터 노출하는 확정 동행 가로 목록
- 이벤트 주차 기준(1~7일, 8~14일 등)과 가로 목록/종료 회색 표현
- 카테고리 첫 칸 ‘당! / 지금’, 상세 ‘지금이당!’, 기타 필터

실제 AI 행사 자동 수집은 후속 작업이다. 이번 화면은 예시 행사를 사용한다.
