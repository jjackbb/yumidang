# 로컬 완성본 확인

현재 주소: http://127.0.0.1:4193/?demo=1

이 주소는 현재 개발 컴퓨터에서 실행 중인 최신 프로덕션 빌드다. 서버가 꺼졌다면 프로젝트 폴더에서 아래 명령으로 다시 연다.

```bash
npm run build
npm run preview -- --host 127.0.0.1 --port 4193
```

`?demo=1`에서만 상단의 **체험 설정**이 보인다. 여기서 역할·시간·02 프로필·04 공고 폼·07 평가 A/B와 시연 시작 구간을 바꿀 수 있다. 데모 초기화는 일반 모드 저장 데이터를 지우지 않는다.

이 미리보기는 프론트 프로토타입이다. 실제 SMS·결제·통화·외부 캘린더·AI·행사 수집·운영 처리 성공을 만들지 않는다. 이전 외부 백엔드 DB·인증 연동은 다른 작업 세션의 범위다.
