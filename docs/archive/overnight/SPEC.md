# 확정 구현 계약

사용자 선택을 구현으로 옮기는 계약이다. 아래 기술 구조는 Codex 설계이며 새 제품 정책 승인이 아니다.

## 1. 공통 구조와 저장

- 기존 React/TypeScript/Vite와 실제 구현을 확장한다. 새 프로젝트·전면 프레임워크 교체 없음.
- 사용자·공개 프로필·공고·신청·초대·대화방·확정 약속·완료 확인·평가·알림이 같은 ID와 상태를 참조한다.
- 상태 갱신은 공통 저장소/도메인 함수로 처리한다. 컴포넌트별 상충하는 복사본을 두지 않는다.
- 데모는 명시적으로 `?demo=1`로 시작하며 데모 데이터 표시, 역할 전환, 시간 전환, 초기화 제공. 일반 서비스 버튼과 체험 조작을 구분한다.
- 탭 이동·창 닫기·새로고침에도 예시 프로필, 작성 공고, 신청, 초대, 대화, 완료 확인, 평가, 알림 설정을 보존한다. 버전 있는 저장 키 사용.
- localStorage/IndexedDB는 프로토타입 저장이다. 파싱 실패·용량 초과 시 현재 화면을 살리고 재시도/초기화 안내를 제공한다. 10MB 사진 원본을 localStorage에 그대로 저장하지 않는다.
- 데모 역할 전환은 같은 저장소에서 서로 다른 userId를 적용한다. 두 실제 기기 간 동기화로 주장하지 않는다.
- 데모에서는 이전 외부 백엔드 auth·쓰기·분석 이벤트 전송을 막는다. 로그아웃 후 개인 대화/동행/설정 접근 제한. 공개 공고는 비회원 열람 가능.
- 기존 공고 변경 재동의, 종료 상태, 확정 후 같은 채팅방 유지, 상세 장소 권한 검사를 보존한다.
- 모든 시간은 유효한 ISO 날짜와 Asia/Seoul 표시를 사용한다. 마감·시작·종료를 혼동하지 않는다.

## 2. 가입·내 프로필 (01 A)

- 헤더는 ‘로그인’. 팝업 위 로그인/가입 두 탭 없음. 하단 ‘휴대폰 본인인증으로 가입’ → 가입 흐름. 로그인으로 돌아갈 수 있음.
- 전화 입력은 숫자만 최대 11자리, 붙여넣기도 동일. 실제 SMS 성공으로 가장하지 않는 인증 체험.
- 실명은 완성된 한글 음절로 검증하되 IME 입력 중에는 조합을 방해하지 않는다. 저장/다음에서 자음·모음 낱자와 다른 문자를 안내.
- 연령대 입력 대신 생년월일. 미래/잘못된 날짜 차단, 공개 프로필은 원본 생년월일 대신 연령대.
- 남성 가입은 추천인 코드 또는 학교/직장 이메일 경로의 앞단 제공. 실제 코드 유효성/이메일 발송은 예시로 구분.
- 첫 가입/첫 로그인 뒤 기본 프로필 미완성이면 짧은 단계로 사진 → 취미·성향 → 소개 → 확인/저장으로 연결.
- JPG/JPEG/PNG 최대 10MB 사진: 등록 → 미리보기 → 저장 → 변경/삭제. 필수 사진이 없으면 재등록 안내.
- 취미·성향 선택, 소개 최대 300자. 연락처 직접 기재·명확한 금칙어는 입력 검증과 수정 안내. 실제 서버 필터 완료로 주장하지 않음.
- Me에서 편집·공개 프로필 미리보기 가능. 같은 사용자의 사진/소개/취미/당도는 모든 화면에서 일치.
- 신규 당도 15. 샘플 기존 사용자는 샘플 수치 표시. 미인증 사용자에게 인증 완료 배지 자동 부여 금지.

## 3. 상대 상세 프로필 (02 A/B 모두)

공고 → 공고 상세·작성자 간단 프로필 → 이름/사진 클릭 → 동일 사용자 상세 프로필.
신청·초대·채팅·약속에서도 상대 userId로 같은 프로필을 연다.
A: 사진·이름·지역·연령대·취미·소개·당도/후기 요약 먼저, 상세 펼치기.
B: 같은 정보를 한 화면에서 연속 스크롤.
검토용 체험 설정에서 A/B를 바꾼다. 실제 사용자에게 매번 두 안 중 선택을 요구하지 않는다.
관심친구 저장·해제, 후기, 신고·차단 진입 포함. 연락처/실명 원본/비공개 후기는 공개하지 않는다.

## 4. 탐색·홈·이벤트 (03 A, 기존 홈 보존)

- 공고 목록 바로 위 카테고리·지역·날짜 필터, 적용 상태·초기화·검색 결과 없음·복귀 제공.
- 홈 종 하나, 신청 도착 큰 박스/사람 모양 신청 아이콘 없음.
- Me 상단 신청한 건/받은 신청 두 탭 유지.
- 확정 약속 중 시작 전 D0~D7만 홈 리마인드, 여러 건은 가로 롤링. 취소·완료 제외.
- ‘지금’은 왼쪽 첫 칸, 아이콘 ‘당!’, 상세 제목 ‘지금이당!’. 기타는 실제 기타 범주.
- 홈 이벤트는 현재 주차에 시작하는 행사. 월별 1~7/8~14/15~21/22~28/29~말일 주차 유지.
- 전체보기: 월·주차 필터 + 가로 이벤트 리스트 + 스크롤 연동 하단 바(버튼 아님).
- 이전 주차 시작 행사 조회 가능, 종료일 당일까지 진행, 이후 회색. 종료 상세 읽기 가능.
- 이벤트 상세 → 해당 eventId의 관련 공고 → 동일 이벤트로 작성. 일반 공고까지 섞거나 다른 행사로 연결하지 않는다.
- 행사 수집/자연어 AI는 10번의 체험 앞단, 실제 수집 성공 문구 금지.

## 5. 공고 작성·수정 (04 A/B 모두)

- A 한 장의 작성 폼 / B 두 단계. 필드·검증·권한·저장 결과 동일, 편집 시 기존 값 복원.
- 기존 제목·카테고리·활동 내용·날짜·시작/종료·모집 마감·공개 동네·상세 장소·태그 필드 보존. 상대 성별 등 선택한 조건 명시.
- 조건 충족자 신청 가능, 미충족자 이유 안내(옛 문서 반대 문구는 오기로 처리). 유료 옵션은 별도 체험.
- 시작 < 종료, 현재 < 모집 마감 <= 시작, 빈 필수값·지난 일정 검증.
- 공고 등록 시 전체 공개. 관심친구 우선 공개 기간 없음.
- 작성자만 수정/마감/삭제. 모집 마감은 동행 완료가 아니다.
- 기존 신청이 있으면 조건 변경을 비교·재동의 처리. 동의만으로 자동 확정하지 않는다.
- 확정된 약속의 변경은 상대 동의 후 적용. 확정 시 다른 후보 종료, 공고/채팅/Me/알림 동기화.
- 기존 일정 겹침 경고 후 진행은 보존, 새로운 강제 제한/취소 페널티 도입 금지.

## 6. 신청·대화·Me 관리 (05 A)

- 직접 신청 → 요청별 대화 가능 → 작성자 최종 수락 시 1:1 확정. 대화 없이 수락 가능.
- 신청자는 자기 신청을 수락할 수 없다. 초대 수신·채팅 시작·조건 재동의가 확정으로 바뀌지 않는다.
- Me: 상단 보낸/받은 신청 + 초대 관리, 작성 공고 및 확정·완료·취소 등 상태별 조회.
- 모든 카드에 현재 상태·연결 공고·상대·가능한 행동 일치. 삭제/만료/취소 대상은 이유와 돌아가기 제공.
- 비당사자는 대화·확정 상세 장소에 접근 불가. 마감되었다는 이유로 상세 주소를 공개하지 않는다.

## 7. 관심친구·초대·알림 (09 A, F/N/S 확정)

### 저장과 공고 연결
- 누구나 단방향 비공개 저장(동행 경험 불필요). 본인·중복·차단/탈퇴/제한 상대는 기존 안전 조건 적용.
- 저장 사실은 상대에게 알리지 않는다. 공개 프로필에 누가 나를 저장했는지 노출 금지.
- 먼저 전체 공개 공고 작성 → 해당 공고로 관심친구 초대 → 상대가 완성 공고 확인 → 직접 신청 → 작성자 최종 수락.
- 사전 ‘관심 있어요’ → 공고 작성 흐름 없음. 초대 클릭만으로 자동 신청/확정 없음.
- 초대는 invitationId/postId/senderId/recipientId/receivedAt으로 같은 공고·사용자와 연결.
- 같은 행동의 중복 클릭은 중복 초대/알림을 만들지 않는다. 재초대 횟수/대기기간 정책은 새로 정하지 않는다.
- 저장 해제는 목록에서 제거. 진행 중 초대·신청·확정 동행을 취소하지 않는다.
- 같은 상대에게 보낸 초대와 받은 초대를 구분. 공고 마감·취소·삭제 시 상태 안내, 신규 신청 제한.

### N1/N2/S2 알림
- 저장 시 사람별 새 공고 알림 기본 ON, 개별 OFF 가능.
- 모든 초대 알림 기본 ON.
- Me > 설정 > 알림에 ‘처음 보는 사람의 초대 알림’ 단일 스위치.
- ‘처음 보는 사람’ = 수신자가 저장하지 않았고 실제 동행 경험도 없는 사람(AND).
- UI에서는 푸시/종을 분리하지 않고 ‘알림’ 하나. 이 스위치를 꺼도 저장한 상대·과거 동행의 초대 알림에는 적용하지 않음.
- 알림을 꺼도 Me 받은 초대 유지. 신규 알림 생성 여부와 초대 수신·목록 저장은 다른 동작.
- 새 공고/초대 알림 선택 → 정확한 공고 상세. 일반 알림함도 최신순 + 종류 필터(06 A).
- 알림은 대상 ID·수신자·생성 시각·읽음 상태를 가지고, 오래된 링크는 대상 현재 상태를 보여준다.

### S1 정렬과 표시
- 기본 ‘최신 초대순’: 수신자가 저장한 사람 우선 묶음, 각 묶음 안 최근 받은순. 이전 동행만으로는 고정하지 않음.
- ‘시간순’: 관심친구 고정·그룹 없이 전체를 동행 시작이 빠른순. 초대 도착 시각순과 구별.
- 이름 옆 ★ 관심친구, ‘동행한 적 있음’ 이전 동행, 둘 다면 둘 다, 처음이면 별도 표시 없음.
- 같은 시작 시각은 수신 시각/ID로 안정 정렬하는 것은 표시의 기술적 타이브레이크다.
- 테스트 데이터에 저장만/동행만/둘 다/둘 다 아님을 모두 넣고 초대순과 시작순을 일부러 다르게 만든다.
- 24시간 초대 기한, 하루3/주10, 6시간 우선 공개, 30일 보관함은 미채택이므로 구현 금지.

## 8. 완료·평가·당도 (P1/P2, 07 A/B 모두)

- 개인별 완료 확인을 기록한다. 공고의 실제 종료 시각부터 가능. 14~15시 동행은 정확히 15시부터. 종료10분 전 허용 없음.
- 내 완료 확인 → 즉시 내 평가 가능. 상대의 완료 확인을 기다리지 않는다. 상대에게 완료 확인 알림(평가 내용은 비노출).
- 완료 확인과 평가 제출은 별개. 제출하지 않고 나갔다가 기간 내 다시 작성 가능.
- 평가 유일키는 appointmentId+reviewerId. 자기 동행의 상대에게만 제출, 중복 클릭/새로고침에도 한 번.
- 작성 기한: 종료 후 7일. 경계는 종료 시각+7일 미만 작성 가능, 정확히 도달 시 마감이라는 기술 해석을 보고서에 명시.
- 내가 상대 평가를 보려면 내 완료 확인 + 내 평가 제출 + 상대 평가 존재가 필요. 양쪽 모두 제출했을 때 공개.
- 7일 뒤 자동 공개는 제거. 한쪽 미제출이면 그 동행 후기는 계속 비공개. 시간 경과로 알림/프로필/미리보기에서 우회 노출하지 않는다.
- 상대가 아직 쓰지 않음 / 내가 써야 볼 수 있음 / 기간 종료로 비공개를 구분.
- A 평가 한 장 / B 별점 → 후기 두 단계. B에 ‘내가 쓴 평가 확인’ 추가 단계 없음.
- 별점·긍정/부정 후기 항목·선택 한마디를 저장, 제출 전에 오류와 검토 제공. 제출 후 공개 대기·공개 상태 연결.
- 신규 당도15, 실제 합산/하한/갱신 자동 계산 보류. ‘합산·하한·갱신 시점 논의 필요’는 검토 화면에 명시.
- 평가 뒤 가짜 상대 평가 타이머·강제+2 점수·가짜 정산 금지. 상대 행동은 명시적 데모 역할로 직접 수행.
- 24시간 자동 완료는 이번 보류. 시간 경과로 개인 확인을 생성하거나 평가 열람을 열지 않는다.
- 둘 다 완료 확인하면 완료 이력, 한쪽만이면 ‘내 완료 확인/상대 확인 대기’를 구분한다.

## 9. 안전·설정·탈퇴 (08 A, P3)

- 짧은 신고/차단 창 + Me 설정 목록. 대상·사유·입력 검증·영향 확인·취소/뒤로가기 제공.
- ‘동행 취소’와 ‘차단’은 별도 버튼. 취소만 하면 차단 관계 없음.
- 차단하면 상대 차단 + 진행 중 확정 동행 취소, 취소 영향 안내 후 실행. 이미 양쪽 완료된 동행/기록은 삭제하지 않음.
- 차단 해제는 관계만 해제, 취소된 동행을 자동 복구하지 않음.
- 신고는 예시 접수 상태·이력, 실제 기관/운영팀 발송이나 자동 제재 없음. 사전 취소와 노쇼를 섞어 자동 감점 금지.
- 권한 거절/계정 제한/탈퇴는 앞단과 영향 안내 제공. 실제 계정·운영 기록 삭제 금지.
- 미확정 E2(한쪽만 완료 후 차단), E3(같은 상대 복수 확정)는 영향 비교/보류 화면을 제공하고 해당 복합 전이를 실행하지 않는다. 데이터나 평가를 지워 처리하지 않는다.
- 초대 재발송·철회·보관기간, 저장 해제 후 새 공고 구독의 지속 정책 등 미확정 경계는 명세 검토용 안내. 정상 확정 흐름은 완성하고 이 경계 때문에 전부 멈추지 않는다.

## 10. 후속 기능 앞단 (10 B)

기능마다 관련 정보와 짧은 체험이 있어야 한다. 모두 똑같은 준비 중 팝업만 띄우는 방식 금지.
- 전화: 상대/연결 동행/통화 이용 조건·마이크 권한 안내, 통화 UI 미리보기. 실제 연결 타이머로 통화 성공 가장 금지.
- PRO/결제: 대상 공고·예시 금액·구성 요약과 결제 앞단. 실제 결제·예치·정산·환불 성공 금지.
- 캘린더: 확정 일정 요약과 추가 화면 미리보기. 실제 외부 캘린더 변경 없음.
- AI 탐색: 예시 문장 → 해석한 카테고리/지역/날짜 조건 → 수정/초기화 → 목록에 적용하는 체험. 규칙/샘플 결과를 실제 AI 호출로 주장하지 않음.
- 행사 자동 수집: 주차·출처·갱신 상태·실패/빈 상태 체험. 예시 행사를 실제 추천 정보로 포장하지 않음.
- 신고 처리/이의제기/계정제한: 상태 안내·상세·복귀 화면. 운영 심사 결과를 자동 확정하지 않음.

## 11. 전체 시연 (11 A/B 모두)

- 가입부터 끝까지 이어가는 전체 체험 + 가입/매칭/동행 후 개별 시작을 모두 제공.
- 일반 가입 사용자의 데이터를 덮어쓰지 않는 명시적 데모 초기화. 역할/시간 전환을 숨기지 않음.
- A/B 비교는 프로필·공고 폼·평가 세 개만 검토 설정에서 선택, 동일 데이터 유지.
- 공통 빈 화면·오류·뒤로가기·닫기·버튼 비활성 이유·키보드 포커스·모바일 안전 영역 확인.
- 상세→프로필 닫기→원래 상세 복귀, 알림→대상→목록 복귀 등 이동 맥락 보존.
- 390×844와 1280×900에서 가로 넘침 없음(의도된 이벤트/리마인드 캐러셀 제외).
- 아침 보고서: 볼 주소, 5분 시연 순서, A/B 위치, 구현 목록, 검사 결과, 보류 기능·실제 연동 한계.
