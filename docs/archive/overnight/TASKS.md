# 단계별 실행 작업

현재 담당은 GPT/Codex다. [GPT 인수인계](GPT_HANDOFF.md)를 먼저 읽고, 완료된 1~3단계를 보존한 채 4단계부터 이어간다. 아래 실행기 결과 형식은 이전 Claude 실행 기록의 형식이며, 현재 Claude 실행기를 켜라는 지시가 아니다.

각 단계는 이전 단계 코드 위에서 진행한다. 목표를 읽고 실제 구현·관련 검증 후 다음으로 넘어간다.
SPEC.md를 우선하고 검토용 스케치의 미선택 제안을 구현하지 않는다.
각 단계 결과는 PROGRESS.md에 파일·검사·남은 문제를 기록한다.
실행기가 .overnight/step-N.json의 done 값과 별도 검사 성공을 모두 확인해야 통과한다.
형식: {"step":1,"done":true,"summary":"...","files":["src/..."],"checks":["..."],"remaining":[]}
실행한 적 없는 검사를 PASS로 적지 않는다. 실패가 있으면 done:false로 기록하고 수정한다.

<!-- STEP:1 -->
## 1. 공통 상태·데모 기반
- 기존 앱, 타입, lifecycle/conversation 함수와 기준 문서를 확인한다.
- 사용자·공고·요청·대화·약속 공통 상태를 재사용/정리하고 관심친구·초대·완료확인·평가·알림 설정 타입을 추가한다.
- 명시적 ?demo=1 모드, 새로고침 보존, 깨진 저장 복구, 데모 데이터 초기화, 역할·시간 전환 기반.
- 데모에서 외부 인증/분석/DB 요청 격리. 신규 당도15와 사용자별 공개정보 공통화.
- 기존 신청→채팅→작성자 수락 흐름의 회귀검사 유지. 의미있는 저장/권한 단위검사.
<!-- ENDSTEP -->

<!-- STEP:2 -->
## 2. 가입·내 프로필·상대 프로필
- SPEC 2~3 전체. 짧은 가입/프로필 단계, 생년월일, 한글 이름, 남성 경로, 11자리 번호.
- 사진 미리보기·저장·변경·삭제·형식/10MB 검증, 취미/성향, 소개300자, 편집/공개 미리보기.
- 신규/미인증 계정의 당도·배지 정확히 표현.
- 상대 상세 A 요약/펼치기 + B 스크롤, 검토 설정 전환. 모든 상대 진입점 연결.
- 불완전 프로필 복귀, 입력 오류/재시도, 개인정보 비노출 점검.
<!-- ENDSTEP -->

<!-- STEP:3 -->
## 3. 탐색·공고 작성 A/B·Me
- SPEC 4~6 전체. 기존 홈 수정 회귀를 유지하고 필터·이벤트 관련 공고·작성 연결.
- 공고 한 장/두 단계 두 안. 동일 필드 검증·편집, 상대조건, 일정·마감, 재동의 연결.
- Me 신청 두 탭과 상태별 작성/확정/완료/취소 조회. 초대 관리용 진입 골격.
- 선택적 사전 대화·작성자 수락·1인 매칭·마감/삭제/취소가 같은 상태로 보이게 검증.
<!-- ENDSTEP -->

<!-- STEP:4 -->
## 4. 관심친구·초대·알림 전체
- SPEC 7 전체. 저장/해제·목록·사람별 새 공고 알림.
- 전체 공개 공고 작성 후 초대, 상대 수신·직접 신청·작성자 수락까지 연결.
- Me 보낸/받은 신청·초대, 최신 초대순/시간순, ★/이전동행 관계 표시.
- 알림 최신순/유형필터·대상 이동·읽음, 모든 초대 기본 알림, 처음 보는 사람 단일 설정(AND).
- 4종 관계 데모 데이터. 시간순 고정 해제, 알림OFF에도 초대유지, unsave에도 진행 관계 유지 검사.
<!-- ENDSTEP -->

<!-- STEP:5 -->
## 5. 완료·평가 A/B·안전/설정
- SPEC 8~9 전체. 개인별 완료, 정확한 종료/7일 경계, 중복 평가 방지, 양쪽 제출 공개.
- 상대 확인 대기와 개인 평가 권한 분리. 공개 프로필/알림/미리보기에서 후기 우회 노출 없음.
- 평가 두 안, 당도 자동 계산 보류, 가짜 점수/타이머 제거.
- 동행 취소/차단 분리, 일반 확정 차단은 취소 연결, 해제와 이력 보존.
- 신고/설정/탈퇴 앞단, E2/E3 미정 경계는 전이 없이 보류 화면.
- 날짜 경계·권한·이중 클릭·새로고침 재진입·숨겨진 후기 검사.
<!-- ENDSTEP -->

<!-- STEP:6 -->
## 6. 후속 기능·전체 시연·브라우저 통합검증
- SPEC 10~11 전체. 기능별 체험 앞단과 전체/구간 시연.
- 전체 코드·화면 연결을 검토하고 핵심 죽은 버튼/막힌 경로/상태 불일치/콘솔오류를 수정한다.
- CHECKS.md 기준의 tests/browser/overnight.cjs를 작성하고 실제 Chromium에서 실행한다.
- 기존 브라우저 회귀 테스트도 새 확정 정책에 맞춰 유지/보완한다. 삭제하거나 기대조건을 약하게 만들지 않는다.
- npm run lint, npm test, npm run build 실행. 모바일/데스크톱 증거와 테스트별 JSON 결과 저장.
- tests/browser/overnight.cjs는 CHECK_URL/PLAYWRIGHT_MODULE/BROWSER_EXECUTABLE/EVIDENCE_DIR을 받으며 실패하면 0 아닌 종료코드 반환.
- 모든 테스트를 새 흐름에서 실제로 통과할 때까지 코드 수정. 알려진 미정 정책·실제 외부연동은 NOT_RUN/보류로 보고.
- MORNING_REPORT.md 완성: 주소, 시연 순서, A/B 위치, 구현/보류, 검증 파일. 이 보고를 적는 것만으로 작업 완료 처리하지 않는다.
