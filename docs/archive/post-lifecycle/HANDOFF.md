# 2차 구현 기록 — 공고 마감·조건 변경과 신청 상태

현재 작업은 [전체 초안 선택](../design-selection/SKETCHES.html)이다. 사용자의 최신 지시에 따라 Codex는 설계를 맡고, 사용자 선택이 모이면 2026년 10월 7일까지 사용자 지정 Claude Opus 5로 묶음 구현한다. [현재 작업 기준](../design-selection/WORKFLOW.md)이 아래 기록보다 우선한다. 아래 구현 방식들은 개별 UX·정책을 모두 사용자 승인받았다는 의미가 아니다.

## 기준

사용자 `ㄱㄱ`로 다음 흐름 진행을 지시했다. 최신 [MVP](https://app.notion.com/p/3db626093f2e80c89662e7104fad9795), [기능명세](https://app.notion.com/p/3d5626093f2e8031927bf5d680bebe67)를 다시 조회했고 `OLD DATA_참조x`는 제외했다. 구현 기준은 POST-02/03/04, MATCH-05/07/08/09, CHAT-01/02/03/04다.

이미 확정된 사용자 결정 유지: 작성자 최종 수락 즉시 확정, 신청 후 대화 선택 가능, 공고 종료 시각부터 완료 가능. 종료 10분 전 허용은 적용하지 않았다.

## 구현

- 작성 화면에 모집 마감 날짜·시각. 기본은 시작 시각, 직접 조정 가능. 현재 이후이면서 시작 시각 이하로 검증한다. 기존 샘플 공고는 시작 시각을 마감으로 보완한다.
- 마감·만료·삭제를 요청 상태와 채팅, 알림까지 한 전이 함수에서 갱신한다. 종료 이유를 구분하고 기존 대화를 보존한다. 수동 마감은 1/2명을 유지하며 매칭을 생성하지 않는다.
- 삭제된 공고는 공개 목록에서 제외하고 옛 신청 링크에는 삭제 안내를 제공한다. 확정/완료 약속이 연결된 공고는 직접 수정·삭제를 막는다.
- 일정·공개 장소·상세 장소·활동 내용·제목·분류·상대 조건·유료 구성이 바뀌면 기존 신청자가 각각 재확인한다. 태그만 수정하거나 같은 조건을 저장하는 것은 재동의 대상이 아니다. 모집 마감 변경 자체는 참석 조건 변경으로 취급하지 않고 새 마감 시각을 적용한다.
- 변경 전·후 비교에 비공개 상세 주소는 노출하지 않는다. 수정이 반복돼도 마지막으로 동의한 조건을 기준으로 비교하고 이전 버전의 응답을 거부한다. 원래 동의한 조건으로 완전히 되돌리면 재확인 대기가 해제된다.
- 변경 동의는 요청을 수락 가능 상태로 되돌린다. 매칭은 작성자 최종 수락으로만 생성한다. 변경 거절은 해당 신청만 종료한다.
- 확정 이후 변경은 기존 채팅 제안에서 상대가 수락한 뒤 적용한다. 약속의 날짜·종료 시각·표시 장소·상세 장소와 원본 공고의 일정·비공개 상세 장소를 같이 갱신한다. 공개 지역에는 조율한 상세 장소를 복사하지 않는다.
- 확정 취소는 당사자에게만 허용하며 사유를 기록한다. 완료 동행은 취소하지 못한다. 취소 후 미확정 후보를 되살리거나 공고를 자동 재개하지 않는다. 약속 이력은 남고 홈 리마인드·채팅 입력·통화·완료/평가·도착 알림은 제한된다.
- 일정 겹침은 공고 작성·참여 신청·작성자 수락·확정 일정 변경 수락에서 경고한다. 일부 시간이 겹치면 중복이며 `[시작, 종료)`를 적용해 맞닿는 일정은 중복으로 세지 않는다. 기존 약속은 자동 취소하지 않는다.
- MATCH-04의 중복 금지 문구와 MATCH-08의 초기 경고 정책이 상충한다. 이번 프론트는 더 구체적인 MATCH-08의 ‘초기 경고 중심’을 적용했다. 강제 차단·예외와 취소 제재는 후속 판단이다.
- Me에 본인 작성 공고 진입점을 추가했다. 약속 상세의 상대 정보도 공용 프로필과 연결해 고정 당도 99를 제거했다.

## 검증과 경계

브라우저 테스트는 이전 외부 백엔드 요청을 가로채는 프론트 시뮬레이션이다. 실제 계정 간 전송·영속 저장·운영 서버 만료 작업·서버 원자적 확정은 검증하지 않았다. 새로고침하면 초기화된다.

- 단위 테스트: 역할/상태 전이, 1인 매칭, 동의 버전, 정확한 만료 시각, 개인정보 표시, 취소, 부분/자정 경계 중복.
- `tests/browser/post-lifecycle.cjs`: 마감, 삭제, 정확한 만료, 작성자 변경/신청자 응답, 거절, 확정 취소, 신청·수락·제안의 중복 경고, 새 공고 마감 검증, 변경한 상세 장소의 참여자/비회원 공개 범위.
- `tests/browser/conversations.cjs`: 기존 신청/대화/수락/완료/평가 6개 회귀 흐름. 취소 사유 입력을 반영했고 `EVIDENCE_DIR`로 별도 출력 경로를 지정할 수 있다.
- 테스트 도구는 `PLAYWRIGHT_MODULE`, `BROWSER_EXECUTABLE`, 대상은 `CHECK_URL`로 지정한다. `CASE`로 특정 사례를 실행할 수 있다. 로컬 빌드 미리보기 주소 `http://127.0.0.1:4180`.
- 첫 검증의 시간 표기 기대값은 실제 오후 시각 표시와 달라 바로잡았다. 마감 경계는 브라우저 시계를 고정하고 React 갱신을 기다린 뒤 시각을 다시 확인한다. 경계 시각을 뒤로 미뤄 통과시키지 않았다.

후속: 완료 권한·평가 공개·당도 갱신 정책 판단 후 3차 연결. 취소 제재·관심친구 등 미결정 기능을 임의로 없애지 않는다.
