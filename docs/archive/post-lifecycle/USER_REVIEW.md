# 2차 — 공고 변경과 종료 직접 확인하기

[앱](https://yumidang6.vercel.app) · [클릭해 보는 흐름 설명](FLOW.html)

시작: 로그인 → 인증번호 발송 → 테스트코드 입력 → 인증 확인 및 로그인.

1. **Me → 내가 쓴 공고 → 성수동 디저트 공고 → 공고 수정**. 시작·종료 시각 또는 공개 만남 장소를 바꾸고 저장한다.
2. **Me → 받은 신청**. 두 신청 모두 ‘변경 조건 확인 필요’이고 수락은 잠겨 있다. ‘대화하기’에서 변경 전·후 내용을 본다.
3. 체험 계정의 **신청자 응답 시연 → 신청자 동의 시연**을 누른다. 해당 신청만 수락 가능해지며 아직 확정은 아니다. 작성자가 수락하면 같은 방에서 확정된다.
4. 신청자 화면은 **채팅 → 주말 사진전 방 → 프로토타입 시연 도구 → 작성자 조건 변경 시연**으로 본다. 변경에 동의하거나 거절하면 Me·채팅 상태가 함께 바뀐다.
5. 새로고침 후, **Me → 내가 쓴 공고**에서 모집 마감·삭제를 확인한다. 마감은 매칭 확정이 아니며, 삭제 후에도 Me의 지난 신청에서 안내를 볼 수 있다.
6. 확정한 약속의 **약속 상세 → 확정 동행 취소**에서 사유를 선택한다. 취소 뒤 홈 리마인드에서 빠지고 채팅·완료·평가가 제한된다.
7. 홈 **전시 → 오후 사진전 14:30~15:30**에 신청하면 기존 브런치 일정과 겹친다는 경고를 본다. 돌아가면 신청문이 유지되고, 계속 진행해도 기존 약속이 자동 취소되지 않는다.

모집 마감 시각은 작성·수정 화면에서 직접 설정한다. 기본값은 동행 시작 시각이다. 마감 시각이 지나면 미확정 신청이 만료되고, 이미 확정된 동행은 유지된다.

신뢰·당도 및 취소 제재 정책의 실제 적용은 다음 단계다. 상태는 현재 앱 세션에서만 유지되며 실제 상대방 전송·서버 저장은 구현하지 않았다. 사용자 직접 확인: 대기.
