# 공고·프로필 연결과 종료 시각 기준 완료 — 2026-09-15

대상: `jjackbb/yumidang6` 프론트 프로토타입. 최신 사용자 지시를 9월 14일 분석보다 우선한다.

## 사용자와 확정한 동작

1. 공고 선택 → 공고 상세 내용과 작성자의 간단한 프로필 → 프로필 클릭 → 해당 유저의 상세 프로필.
2. 완료 가능 시각은 **공고에 정한 종료 시각**이다. 14:00~15:00 공원 산책은 14:50·14:59에는 잠기고 **15:00부터** 완료할 수 있다. 완료 처리 후 평가가 열린다.
3. ‘종료 10분 전부터 허용’은 **논의사항**이며 적용하지 않는다. 모집을 조기 마감하는 것과 동행 종료는 구분한다.

## 구현

- 공고 소개, 시작·종료 일시, 장소, 사전 안내와 간단한 프로필을 상세에 표시한다. 프로필에서 돌아오면 같은 공고와 스크롤 위치를 유지한다.
- 상세 프로필: 사진·이름, 지역·연령대, 자기소개, 취미·성향, 당도·인증 정보, 공개 후기. 사용자 ID별 예시 데이터이며 없는 정보는 미등록으로 표시한다. 예시 프로필과 후기는 화면에 시연용이라고 표시한다.
- 공고 작성·수정에 상세 소개와 종료 날짜·시각을 추가한다. 종료 ≤ 시작은 거부하며 다음 날 종료도 지원한다.
- 공고의 `startsAt/endsAt`이 약속의 `scheduledAt/endsAt`으로 전달된다. 수정된 공고와 채팅 일정 변경에도 종료 시각을 함께 반영한다. 완료 이력은 기존 약속의 기록을 유지한다.
- `completionAvailability`가 완료·평가 버튼과 실제 처리 함수에 같은 기준을 제공한다. 미로그인·비참여자·미확정·취소·종료 시간 누락/오류는 잠금 상태다. 종료 시각에 화면을 갱신하며 처리 시 현재 시간을 다시 확인한다.
- 완료 후에는 Me 목록에서 해당 약속을 다시 열 수 있다. 완료와 평가를 별도 상태로 관리한다.
- 평가 제출 내용은 사용자·약속별로 프론트 상태에 보관한다. 창 닫기·재진입·다른 약속 이동으로 중복 제출하지 않으며 상대 평가 시연도 한 번만 반영한다. 기존 자동 상대 평가 타이머를 제거하고 명시적인 시연 버튼을 유지한다.
- 공고 상세의 비밀 장소는 작성자 또는 확정 참여자에게만 표시한다. 단순 모집 마감 여부로 공개하지 않는다. 프론트 표시 제어이며 서버 보안을 구현했다는 의미는 아니다.
- 이벤트 내 공고도 먼저 공고 상세로 연결한다.
