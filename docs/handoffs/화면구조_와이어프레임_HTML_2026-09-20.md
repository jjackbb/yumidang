# 화면 구조 와이어프레임 HTML — 인수인계

작성: 2026-09-20 · 산출물: `docs/planning/design/yumidang-wireframes.html` (단일 파일, 외부 의존 없음)

## 무엇인가

팀 합의용 **검토 도구**다. 실제 서비스 코드·DB·설정은 건드리지 않았다.
`SCREEN_INVENTORY.md` / `STITCH_PROMPTS.md` / `DESIGN.md` / `01_POLICY_HANDOFF.md`를 읽고 만들었다.
사용자 검증 결과나 최종 설계 확정이 아니다.

## 여는 방법

Finder에서 `docs/planning/design/yumidang-wireframes.html`를 더블클릭하거나 브라우저로 연다.
설치·서버·로그인 불필요. 외부 API·이미지·라이브러리를 전혀 쓰지 않는다.

## 구성

- **A. 전체 화면 보기** — 24개 주요 화면·흐름을 축소 모바일 프레임으로 나란히 배치.
  ID / 화면 이름 / 해결하는 과업 / 주요 연결 화면 / 형태(탭·전체화면·바텀시트·모달·화면 내 단계) 표시.
  아래에 **SX 보조 기능 범위 검토 목록 8개**와 **화면 밖 검토 메모 10건**.
- **B. 한 화면 상세 보기** — 왼쪽 화면 목록·검색 / 가운데 390px 와이어프레임 / 오른쪽 컴포넌트 설명·이동 경로·배치 변경 이유·정책 확인 필요·관련 결정 ID.
  좁은 브라우저에서는 와이어프레임이 먼저 오고 목록과 메모가 아래로 내려간다.
- **상태 전환 도구**는 화면 밖 툴바에 있다. 정상·빈 목록·오류·비로그인·마감 등을 비교하고, S11은 신청자/작성자 역할도 전환한다.
- 고정/스크롤 구간은 프레임 **바깥 레일**에 표시해 화면을 가리지 않는다. 토글로 끌 수 있다.

## 확인한 것 — 1차(초판, 2026-09-20 오후)

- 24개 화면 × 모든 상태 × 역할 전수 렌더 — 오류 0
- 화면 간 링크·`data-go` 대상 무결성 — 끊긴 연결 0
- 프레임 내부 가로 넘침 0, 고정 영역 겹침 0, 페이지 가로 스크롤 없음
- 콘솔 오류 없음(폼 라벨 관련 접근성 권고만 남음)
- 핵심 흐름 동작: S01→S02→S08→신청→S11, 뒤로가기, 탭 이동, 입력값 보존,
  인사 문구 칩은 입력창에 채우기만 하고 버튼을 눌러야 전송

## 확정 기준 반영

기본 탭 4개 유지 / 작성자 수락이 최종 확정 / 공개 장소는 시·구·동까지 /
타인 공개 프로필은 로그인 후 / 프로필 사진 필수·마지막 사진 단독 삭제 불가·교체 실패 시 기존 사진 유지 /
마스킹 이름·`25세`·기본 `15당` / AI 브리핑 캡션 원문 유지 /
완료·평가 규칙(양쪽 완료 가능, 예상 종료+24시간 자동완료, 완료 알림 확인 시점부터 24시간 보류, 평가 7일, 분쟁 시 정지·재개 최소 24시간 보장).

미확정 6개(연령 하한 18/19, 취향·MBTI 필수 여부, 별점·후기·태그 조합, 신고·차단·확정 취소 범위,
AI 요약 노출·검색 진입, 종료 행사 새 공고)는 임의로 정하지 않고 점선 `검토 필요` 상자와 오른쪽 메모로 분리했다.

## 다음 담당 — 1차 시점

# 5차 수정 — 채팅방 및 관련 UI 개선 (2026-09-21)

근거: 사용자의 추가 요구사항 (채팅 목록 컬러, 채팅방 컴포저 및 상단 정보, 상태 변화 등).

## 바꾼 것
- **채팅 목록 S10**:
  - `매칭 확정` 배지 색상을 초록색(`ok`)에서 보라색(`v`)으로 변경.
- **채팅방 S11**:
  - 컴포저에 **`+` (이미지 첨부)** 버튼 추가 (레퍼런스 이미지 반영).
  - 시스템 알림 메시지 날짜 표시 제거 (`9월 15일 · 박*은님이 동행을 신청했어요.` → `박*은님이 동행을 신청했어요.`).
  - 상단 안내 바 2종(작성자 수락 대기, 상태 바)을 **신청한 동행 공고의 간략한 버전(미니 카드)**으로 통합하여 상단에 고정 표시.
  - 상단 타이틀 영역: 작성자 이름 클릭 시 **S14(상세 프로필)**로 이동하도록 변경.
  - 상단 우측 버튼: `프로필` 텍스트 대신 **`⋮` (더보기)** 아이콘으로 변경하고, 클릭 시 바텀 시트(`신고하기, 차단, 신청 취소`) 호출.
  - 일정 변경 제안(`proposal`) 상태: `변경 조건 확인 필요` 배지를 **`제안중`**으로 변경하고, 화면 중앙에 팝업 알림 추가.
  - 확정됨(`confirmed`) 상태: 알림 텍스트와 UI 배색을 초록색에서 보라색(`var(--vio)`)으로 변경하고 상세 주소(종로구 소격동...) 추가.
  - 종료(`ended`) 상태: `신청 취소 · 이전 대화는 볼 수 있지만 새 메시지는 보낼 수 없어요.` 박스를 없애고, 하단 컴포저의 입력창과 전송 버튼을 **회색 비활성화** 상태로 표현.
  - 전송 실패(`fail`) 상태: `다시 시도` 텍스트를 **새로고침(↻) 아이콘**으로 대체.

## 확인한 것
- S10: 확정 배지 보라색 표시 확인.
- S11: 
  - 컴포저 입력창 좌측 `+` 아이콘 렌더링 확인.
  - 시스템 알림 문구 날짜 제거 확인.
  - 상단 헤더에 신청 공고 요약(배지, 제목, 일시·장소) 및 프로필 진입 링크 렌더링 확인.
  - 우측 `⋮` 아이콘 및 더보기 바텀 시트 렌더링 확인.
  - `proposal` 상태 팝업 표시 및 `제안중` 라벨 확인.
  - `confirmed` 상태 보라색 안내 문구와 주소 표시 확인.
  - `ended` 상태에서 하단 입력창 비활성화 스타일 적용 확인.
  - `fail` 상태 ↻ 아이콘 표시 확인.

## 남은 결정
