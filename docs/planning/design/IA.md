# 유미당 IA — PRD 반영 정보 구조

## 기준

- 기준 문서: [유미당 PRD](../requirements/PRD.md).
- 단계별 진입·분기·완료 흐름: [유저 플로우](USER_FLOW.md).
- 출발점: 사용자가 제공한 기존 IA. 홈·둘러보기·채팅·나의 4개 기본 탭과 S00~S20, S09-2·S09-3·S15-2 화면 ID를 유지한다.
- 사용자 확정 가입·이용 대상: **성인 여성만 가입·이용할 수 있다.** 동행 요청자·제공자 모두 여성 사용자이며, 향후 전문 동행·유료 오퍼도 같은 자격을 적용한다. 남성·미성년 사용자와 추천 코드·기관 이메일을 통한 예외 가입은 제공하지 않는다.
- 초기 제품 범위: 성인 여성 대상 무료 1:1 동행 매칭. 휴대폰 인증 → 상대 탐색·신뢰정보 확인 → 신청·대화 → 상대 선택·양측 확정 → 실제 동행 → 상호 평가의 흐름을 연결한다.
- 이 문서는 PRD를 반영한 목표 구조다. 현재 코드·와이어프레임의 구현 완료를 뜻하지 않는다. 이전 화면 구조·시안 분석은 [과거 기록](../../archive/design-selection/README.md)으로 분리했으며, 현재 변경점은 아래 표에 정리한다.
- 행사·알림·사진 관리·취소 등 기존 보조 경로는 유지한다. PRD가 상세 정책을 정하지 않은 부분은 별도 확인 항목으로 남긴다.

## 기존 IA에서 바뀐 부분

| 영역 | 기존 IA | PRD 반영 |
|---|---|---|
| 서비스 타깃·가입 자격 | 여성 중심 타깃, 기존 남성 가입 분기 포함 | 성인 여성만 가입·이용 가능하며 남성·미성년 및 예외 가입 경로 없음 |
| 둘러보기 필터 S01 | 작성자 성별·나이 필터 | 여성 타깃 IA에서 작성자 성별 필터를 제외하고 나이 필터 유지 |
| 가입·인증 S05·S06 | 기본 프로필·조건 확인 중심의 연결 | 휴대폰 본인인증과 성인 여성 자격 확인을 필수로 연결하고, 기존 회원도 같은 이용 자격 적용 |
| 성향·취미 S15-2 | 프로필 편집과 가입 조건 분기에 함께 등장 | 가입 후 성향·취미 등록과 이후 수정 경로를 명시 |
| 가입 조건 S07 | S06 다음의 남성 가입 조건 확인 경로 | 여성 타깃 IA의 서비스 경로에서 제외하고 기존 ID는 과거 참조로 보관 |
| 상대 조건 S04·추천 코드 S13 | 상대 조건 설정 및 기존 남성 가입용 추천 코드 경로 | 상대 성별 선택과 일반 서비스의 추천 코드 항목 제외 |
| 신뢰정보 S14·S13 | 공개 프로필·후기·당도 영역 | 초기 인증정보, 이후 완료된 동행이력·상호 후기·당도를 상대 판단 정보로 연결 |
| 상대 선택·확정 S11 | 작성자 수락 → 확정 상태 | 작성자의 상대 선택과 양측 동행 확정을 구분하고 확정 대기·완료 상태 표시 |
| 받은 신청 S13 | 수락하기 → S11 | 신청자 성향·취미 확인 → 대화·상대 선택 → 양측 확정의 경로로 정리 |
| 약속·완료·평가 S16·S17 | 약속 상세에서 평가 화면으로 이동 | 확정 후 상세 정보 확인 → 실제 동행 → 종료·완료 확인 → 상호 평가 → 신뢰정보 축적을 명시 |
| 무료·유료 범위 | 유료 오퍼의 위치가 드러나지 않음 | 초기 무료 1:1 동행과 향후 전문 동행·유료 거래 검토 범위를 구분 |

PRD는 작성자가 상대를 직접 선택하고 양측이 동행을 확정한다고 설명한다. 이 IA는 두 개념을 분리해 표시하며, 별도 확인 버튼의 수·동작이나 신청 시 동의의 효력까지 확정하지 않는다. 채팅방 생성 자체는 확정으로 표시하지 않는다.

## 정책 확인이 필요한 부분

- **가입 자격과 기존 계정:** 성인 여성만 가입·이용 가능하며, 남성·미성년과 추천 코드·기관 이메일을 통한 예외 가입은 허용하지 않는다. 기존 회원도 같은 자격을 적용하고, 미확인 상태에서는 본인인증·자격 확인을 거쳐야 한다. 구체적인 인증 수단, 성인 판정 기준, 정보 오류 정정 절차와 기존 계정의 전환·보관·삭제 절차는 별도 확인한다. 과거 S07 남성 가입 분기는 서비스 경로에 포함하지 않는다.
- **인증과 공개 범위:** PRD의 실명·실제 나이 인증 목표를 반영하되, 인증 수단·확보 가능한 정보는 별도 확인한다. 이름 마스킹 여부, 비회원 공개 범위는 기존 정책과 대조한다. 생년월일 원본을 공개 프로필 항목으로 추가하지 않는다.
- **프로필 입력:** 성향·취미 등록 경로는 포함한다. 사진·취향 입력의 필수 여부, 건너뛰기, 가입 완료의 정확한 시점은 상세 가입 정책에서 정한다.
- **양측 확정:** 신청자의 최초 신청을 동의로 볼지, 작성자 선택 후 신청자가 다시 확인할지 결정이 필요하다. 기존 작성자 단독 수락 상태 전이를 그대로 PRD 충족으로 간주하지 않는다.
- **채팅:** 신청 후 대화하는 기본 흐름을 반영한다. 채팅을 건너뛸 수 있는지, 최소 대화 조건이 있는지는 새로 규정하지 않는다.
- **완료·후기·당도:** 실제 동행 완료를 확인하는 방식, 평가 공개 시점·작성 기한·당도 계산·보복성 리뷰 대응은 상세 정책을 따른다. 데이터가 없는 사용자에게 동행이력이나 신뢰 수치를 임의로 부여하지 않는다.
- **기존 보조 기능:** 12개 카테고리·나이 필터·행사·알림·일정 변경·신고·차단·취소는 기존 IA를 유지한 항목이다. 작성자 성별 필터는 여성 타깃 구조에서 제외한다. 나머지 구체적인 처리 규칙을 PRD의 확정 정책으로 추가하지 않는다.
