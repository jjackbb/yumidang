# 1차 확인 — 신청 → 대화 → 작성자 수락

사용자 결정: **작성자가 최종 수락하면 동행 확정**. 신청 직후부터 대화할 수 있으며, 대화를 생략하고 바로 수락하는 것도 가능하다.

## 바로 눌러볼 순서

1. [유미당](https://yumidang6.vercel.app)에서 로그인 → 인증번호 발송 → 테스트코드 입력 → 인증 확인 및 로그인.
2. **Me → 받은 신청 → 김*수 프로필**을 확인하고 돌아온다.
3. **대화하기**에서 메시지를 보내고 홈에 갔다가 채팅으로 돌아온다. 대화와 작성 중인 문장이 유지된다.
4. **동행 수락하기**를 누른다. 같은 대화방이 ‘매칭 확정’으로 바뀌고 약속 상세로 연결된다.
5. 채팅 목록에서 다른 신청자의 방을 연다. ‘다른 동행자와 확정’ 사유와 이전 대화만 보인다.
6. 신청자 입장은 홈 **지금 → 서울숲 커피 공고 → 참여 신청**으로 확인한다. 확정 체험은 대화방의 **프로토타입 시연 도구 → 작성자 수락 시연**에서 가능하다.

통화 버튼과 PRO 버튼은 기능 소개·구성·예시 금액을 보여주는 준비 중 화면이다. 실제 통화·결제·예약은 실행되지 않는다.

## 이번에 확인할 것

- 신청과 확정을 구분할 수 있는가?
- Me·알림·채팅에서 같은 상대와 공고로 이동하는가?
- 작성자가 수락하면 바로 확정된다는 안내가 충분한가?

실제 사용자 확인: 대기. 앱 내 상태는 탭 이동 동안 유지하며 새로고침하면 초기화된다. 실제 두 계정 간 메시지 전송·서버 저장은 이번 구현 범위가 아니다.
