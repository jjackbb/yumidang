# 와이어프레임 수정 요청 전달

- 작성일: 2026-09-22
- 대상: [yumidang-wireframes.html](../design/yumidang-wireframes.html)
- 목적: 사용자가 검토한 화면별 수정 요청과 추가 검토 의견을 전달한다.
- 상태: 요청 사항을 기록한 문서이며, 이 문서 작성으로 와이어프레임을 변경한 것은 아니다.
- 구분: 1장은 구체적인 수정 요청, 2장은 추가 정리·검토가 필요한 항목이다. 검토 의견을 임의로 최종 설계로 확정하지 않는다.

## 1. 구체적인 수정 요청

### S05 로그인·본인인증

#### 이용 자격 미충족

- 기존: “성인 여성만 이용할 수 있어요. 추천 코드나 기관 이메일로 예외 가입할 수 없어요.”
- 변경: “성인 여성만 이용할 수 있어요”

### S06 가입 프로필

#### 프로필 입력

- 프로필 사진을 중앙에 배치한다.

#### 가입 완료

- ‘프로필 입력’, ‘사진 필요’ 상태에서 사진 등록 조건을 충족하고 가입을 완료하면, 가입 완료 안내 팝업창을 표시하고 홈으로 이동한다.
- 별도의 ‘가입 완료’ 화면을 삭제한다. S06 가입 프로필 전체가 아니라 가입 완료 상태/화면을 삭제하는 요청이다.

### S07 학교·직장 이메일 인증

#### 메일 전송됨 / 지원 도메인 확인 / 코드 만료

- “검토용 코드: 123456” 안내를 삭제한다.

### S22 1원 계좌 인증

#### 1원 전송·입력 / 예금주 불일치 / 코드 만료 / 요청 실패

- “검토용 코드: 1234” 안내를 삭제한다.

### S00 홈

#### 이벤트 배너와 본문 순서

- 이벤트 배너를 가로로 롤링하는 배너로 변경한다.
- ‘전체보기’는 이벤트 배너의 우측 위에 텍스트로 배치한다.
- 본문 배치 순서는 **이벤트 배너 → 다가오는 약속 → 어떤 동행을 찾으세요?**로 변경한다.

#### 로그인 정보와 알림

- 로그인한 사용자 정보 또는 비로그인 상태의 ‘로그인’ 버튼을 상단 알림 버튼 좌측에 배치한다.
- 기존 텍스트 ‘알림’ 버튼은 종 아이콘으로 변경한다.
- 로그인한 사용자 정보에는 실명만 표시한다. 예: `김*은`이 아니라 `김지은`.
- 해당 영역에서 인증 아이콘·나이·당도는 제거한다.

위치·표시 변경 대상:

```html
<div class="box info">김*은 <span class="vchk" title="휴대폰 본인인증" aria-label="휴대폰 본인인증">✓</span> · 25세 · 15당</div>
<button class="btn p" data-go="S05">로그인</button>
<button class="btn xs" data-go="S12">알림</button>
```

#### 행사 불러오기 실패

- ‘다시 시도’ 버튼을 새로고침 아이콘으로 변경한다.
- 새로고침 아이콘은 “행사를 불러오지 못했어요.” 텍스트 우측에 배치한다.

변경 대상:

```html
<button class="btn s" data-state="default">다시 시도</button>
<div class="box info">행사를 불러오지 못했어요.</div>
```

### S03 공고 작성·기본 정보

#### 작성 — 일정

- 현재 동행 날짜 입력을 시작과 종료로 분리한다.
- **동행 시작 날짜/시간**, **동행 종료 날짜/시간**을 각각 선택할 수 있게 변경한다.

#### 작성 — 만남 장소

- ‘장소명 검색’, ‘주소로 찾기’ 버튼을 세로가 아닌 가로로 배치한다.
- 좌측은 ‘장소명 검색’, 우측은 ‘주소로 찾기’로 배치한다.
- “주소 후보를 선택해 주세요.” 문구를 제거한다.

#### 장소명 검색 / 주소 검색

- ‘삼청 전시관’, ‘성수 전시장’ 예시 후보를 고정 표시하지 않는다.
- 최근 검색이 남겨지도록 변경한다.

고정 표시 제거 대상:

```html
<button class="btn place-option" data-act="pick-address" data-index="0"><b>삼청 전시관</b><br><span class="cap">서울 종로구 삼청로 30 · 03062</span></button>
<button class="btn place-option" data-act="pick-address" data-index="1"><b>성수 전시장</b><br><span class="cap">서울 성동구 연무장길 20 · 04782</span></button>
```

#### 행사 연결

- 홈 이벤트 배너와 같이 사진·행사 이름·행사 기간 등을 보여준다.
- 이 화면에서는 롤링하지 않고, 행사 목록을 세로 리스트로 나열한다.
- ‘전체보기’ 버튼을 배치한다.
- ‘전체보기’는 홈 이벤트 배너의 ‘전체보기’를 눌렀을 때 나오는 화면과 같은 목록 화면을 사용한다.
- 이미 진행 중인 행사 또는 진행 예정 행사를 선택할 수 있게 한다.

### S04 공고 작성·확인

#### 등록 완료

- 별도의 ‘등록 완료’ 화면을 삭제한다.
- 등록이 완료되면 바로 등록한 공고 상세 페이지로 이동한다.

### S17 동행 상호 평가

#### 경험 선택

- ‘좋아요 / 보통이에요 / 별로예요’ 버튼을 가로로 배치한다.

### S20 AI 동행·행사 찾기

#### 대화 시작

- 유저가 보낸 채팅은 오른쪽에 배치한다.
- AI 답변은 왼쪽에 배치한다.

사용자가 지목한 예시 문구/요소:

```html
<button class="btn s sm" data-act="ai-example">이번 주말 갈 전시 찾아줘</button>
```

## 2. 추가 정리·검토가 필요한 항목

### S01 U·둘러보기

#### 공고 목록

- 검색창과 필터 UI 전반을 재정리해야 한다.
- **‘동행 비용’과 ‘선택 장소 없음’ 영역은 유지**한다.
- ‘일정’, ‘나이’ 부분은 수정이 필요하다.
- 구체적인 검색창·필터 배치와 일정·나이 입력 방식은 이 요청에서 정해지지 않았다.

### S12 알림

#### 알림 목록

- 알림 목록 UI 전반을 재정리해야 한다.
- 구체적인 수정 형태는 이 요청에서 정해지지 않았다.

### S13 나 → Me

- ‘나’ 명칭을 ‘Me’로 변경한다.
- 현재 상단에 가로로 나뉜 탭 구성을 재검토한다.
- 사용자 검토 의견: 기본을 ‘내 프로필’로 하고, 세로 구조로 바꾸는 방향을 검토한다.
- 세로 구조의 구체적인 형태는 아직 정해지지 않았다.

### S04 공고 작성·확인

#### 등록 확인

- 나이 선택 영역을 수정한다.
- 가로 바 형태로 최소~최대 나이를 정할 수 있게 한다.

#### 계좌 인증 필요

- 사용자 피드백: 해당 상태를 선택해도 아무런 화면 변화가 없다.
- 계좌 인증이 필요한 상태임을 구분할 수 있도록 확인·수정이 필요하다.

### S09-2 공연·전시·축제 목록

#### 이번 주 새로 시작

- 지역 선택이 현재 ‘전체 / 서울 / 부산’으로 되어 있는 부분은 수정이 필요하다.
- 변경할 지역 목록이나 선택 방식은 이 요청에서 정해지지 않았다.
- 기간은 ‘1주차 / 2주차 / …’ 버튼 형식으로 변경한다.
- 각 주차에 해당하는 날짜를 함께 표시한다.
