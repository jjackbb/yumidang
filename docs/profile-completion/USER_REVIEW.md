# 사용자 확인 — 공고·프로필과 완료 시각

반영한 흐름: **공고 → 공고 상세 + 간단 프로필 → 유저 상세 프로필 → 보던 공고로 돌아가기**.

시간 기준: **14:00~15:00 공고는 15:00부터 완료 처리 가능 → 완료 후 평가 가능**.

‘종료 10분 전 허용’은 논의사항이며 현재 적용하지 않았다.

화면을 볼 때는 홈 ‘전시’ 또는 ‘산책’에서 공고를 열고 프로필을 눌러 확인하면 된다. 시간 경계는 [설명용 시각화](FLOW.html)의 ③ 완료와 평가에서 바로 시연할 수 있다.

에이전트 브라우저 검증: 통과. 사용자 직접 확인: 대기. 프로필과 후기는 예시이며 새로고침 시 시연 상태가 초기화된다.
