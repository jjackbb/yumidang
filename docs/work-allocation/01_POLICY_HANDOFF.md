## 이미 결정돼 다시 물을 필요 없는 사항

- Q11·Q12·Q17은 완료·이의제기·평가 기간에 관한 후속 확정이 있다. 원문 상단의 후속 확정을 우선하고 비교용 과거 질문을 다시 투표하지 않는다.
- D-A1~D-A16의 확정 방향을 유지한다. 단 D-A10은 도입 방향과 후기 공개 세부 조건을 구분한다.
- 주소는 **카카오 우편번호 + 카카오 로컬**(D-A13). 과거 ‘네이버 조사 중’은 갱신 누락이다.
- 행사 공급자는 **KOPIS + 서울 문화행사정보 + TourAPI**, 팝업은 운영자 등록 방향(D-A14). 키·약관·연동 가능성은 팀원 2 몫이다.
- AI 2종, 테스트 포텐스닷→이후 Gemini 전환 방향(D-A15)을 유지한다. 공급자 변경이 필요하면 이유를 올린다.
- D-A16 캡션은 **“사용자 리뷰를 바탕으로 동행 성향을 요약했습니다.”** 그대로 유지한다. 안전 안내를 다른 곳에 둘지와 캡션을 되돌리는 것은 다른 결정이다.
- 마스킹 이름, 만 나이 값을 `25세`로 표시, 초기 `15당`, 공고 카테고리 12개, 행사 분류 4개는 유지한다.

## AI 설계에 따로 남아 있던 안건 — 기존 질문과 연결

새 정책을 만들어 늘린 것이 아니라 `AI_FEATURES_DESIGN.md` 6절의 미결정을 담당별로 배정한 것이다.

| 연결 ID | 담당/결과 |
|---|---|
| P3·R1 | 팀원 1: 요약 최소 후기 수와 부정 후기 처리, 캡션 외 보완 안내. 3건은 초안값 |
| AI-ENTRY | 사용자+GPT: 자연어 검색 진입 위치. 팀원 1: 비로그인 이용 허용 여부. S20은 별도 탭 확정이 아님 |
| AI-LABEL | 사용자+GPT: 조건 해석·수정 안내. 팀원 1: 후기 근거의 공개 범위. D-A16 고정 |
| AI-DATA / Q36 | 팀원 1: 외부 전송 고지·동의·로그 보존 검토. 팀원 2: 공급자 처리·보관·학습 조건 조사. 법적 적합성은 미검증 |
| AI-BUDGET | 팀원 2: 예상 요청량·비용·차단 방법을 제시. 비용 책임자가 상한 선택, 사용자+GPT는 실패 화면 설계 |

초안의 ‘후기에서 개인정보가 절대 나가지 않는다’, ‘AI가 지어낼 수 없다’는 검증 결과가 아니다. 자유 후기 자체에 개인정보가 들어갈 수 있으므로 팀원 2가 처리 방법과 실패 사례를 제시해야 한다. 이 한계를 정책 문구에 반영한다.

## 재질문 대신 문서 정합성을 고칠 항목

1. 정책 질문지/결정 기록의 ‘네이버 조사 중’ → 최신 D-A13 참조 표시.
2. D-A15·D-A16이 없는 과거 결정표 → 최신 인수인계 연결. 새 결정으로 재발급하지 않음.
3. README의 초기 당도 50 → D-A12의 15와 충돌 기록. 공용 문서 반영은 통합 담당에게 전달.
4. 후기 공개를 단순 ‘24시간 후 무조건 공개’로 줄이지 않음. Q17 후속 확정의 양측 제출/7일/분쟁 조건을 함께 사용.
5. 예전 정책의 미구현과 최신 코드의 동작을 분리. 실제 테스트 인증을 SMS·실명 인증 완료라고 쓰지 않음.

## 결과 형식과 완료 기준

결과 파일 제안: `docs/product-decisions/TEAM1_RESULTS.md`.

```text
ID / 결정 또는 보류 / 결정자·날짜 / 실제 발언과 근거
정상 사례 / 예외 사례 / 화면 ID와 바꿀 문구·버튼
데이터·권한 영향 / 다른 결정과 충돌 / 검증 전 가설 여부
보류 이유·다시 판단할 조건 / 팀원 2 또는 설계 담당에게 필요한 답
```

한 번에 1~3개 쟁점을 다루고 AI 추천을 팀 결정으로 기록하지 않는다. 숫자·기간을 정하면 근거와 확인 방법도 남긴다. 모든 항목이 확정 또는 이유 있는 보류로 분류되고, 연결된 화면·정책끼리 충돌이 없는지 확인하면 인계 완료다. 실제 운영 담당·보존·개인정보 쟁점은 전문 검토 필요 여부를 명시한다.

## 담당 AI에 전달할 요청문

> 이 파일과 연결된 원문을 읽고 팀원 1의 정책 검토를 도와줘. 화면을 바꾸는 우선 쟁점부터 기존 29개와 추가 10개, AI 설계의 잔여 결정을 빠짐없이 정리해줘. 이미 확정된 D01~D12, Q11·Q12·Q17, D-A1~D-A16은 반복 질문하지 말고 세부 미결정과 진짜 충돌만 다뤄줘. 추천·팀 선택·현재 구현을 구분하고 결과 형식대로 회신해줘. 제품 코드·DB·배포는 이 작업의 대상이 아니야.
